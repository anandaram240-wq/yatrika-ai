## 3. Licensing and Export Implementation Audit (Mandate Section 4)

1. **Alar (`alar.ink`) ODbL v1.0 Obligations:**
   - **Fact:** Alar's official About page specifies that V. Krishna's dictionary corpus is licensed under the **Open Database License (ODbL v1.0)**.
   - **Audit Check Required:** If Antigravity used Alar to populate or verify any of the 15 glossary entries or 22 regional variations:
     - **Attribution:** The UI and `README.md` must explicitly credit *"Alar Kannada–English Dictionary by V. Krishna (`https://alar.ink/`), licensed under ODbL v1.0."*
     - **Share-Alike / Database Rights:** Under ODbL v1.0 (Section 4.4), any redistributed derivative database or JSON export that incorporates substantial parts of an ODbL database must itself be offered under ODbL v1.0 (or identify the ODbL-licensed records distinctly) and cannot be relicensed under a conflicting blanket `CC BY 4.0` license.
2. **Separation of Code License vs. Linguistic Data License:**
   - **Application Source Code (TypeScript/React/CSS):** May be licensed under **MIT** or **Apache 2.0** in the repository `LICENSE` file.
   - **Original Team Metadata & Consented Local Contributions:** May be released under **CC BY 4.0** provided the contribution form displays an explicit affirmative consent checkbox.
   - **Third-Party Cited Lexical Content:** Retains the license of its underlying source (`ODbL v1.0` for Alar, `Public Domain` for Kittel 1894, `All Rights Reserved / Fair-Dealing Citation Only` for Upadhyaya 1976, Venkatasubbiah, Padakanaja, and Bharatavani).
3. **Research JSON Export Audit:**
   - The export function must include `"license_policy": "Composite dataset: Original explanatory metadata CC BY 4.0; Alar-derived lexical entries subject to ODbL v1.0; scholarly citations subject to fair-dealing reference terms"` and preserve per-entry `license_status`. Any code setting a single global `"license": "CC BY 4.0"` on the exported JSON root without qualifying third-party entries is a **P0 Licensing Defect**.
